# Backend — Caminhões API

API RESTful (Node.js, Express, TypeScript, Sequelize e PostgreSQL). A documentação completa do projeto, do Docker e da esteira de CI/CD está no [README da raiz](../README.md).

```bash
cp .env.example .env     # configure o banco (local ou Supabase)
npm install
npm run dev              # http://localhost:3000  (Swagger em /api-docs)
```

Scripts: `npm run dev` · `npm run build` · `npm start` · `npm run type-check`
